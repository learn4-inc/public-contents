入力フォームを作るHTMLの要素

スライド「125-form」で紹介されている (デモページ) の一覧です。

  • 01-text — input type="text"（テキスト入力欄）
  • 02-email — input type="email"（メールアドレス入力欄）
  • 03-date — input type="date"（日付入力欄）
  • 04-password — input type="password"（パスワード入力欄）
  • 05-checkbox — input type="checkbox"（チェックボックス）
  • 06-radio — input type="radio"（ラジオボタン）
  • 07-required — required 属性（必須入力）
  • 08-placeholder — placeholder と value の違い
  • 09-disabled — disabled 属性（無効化）
  • 10-textarea — textarea 要素（複数行テキスト）
