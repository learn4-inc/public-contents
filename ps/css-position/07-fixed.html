固定ヘッダー（position: fixed）

position: fixed のデモ

position: fixed は、ビューポート（ブラウザの表示領域）を基準に要素を固定します。スクロールしても常に同じ位置に留まります。

スクロールして確認してください。ヘッダーが常に画面上部に固定されています。
